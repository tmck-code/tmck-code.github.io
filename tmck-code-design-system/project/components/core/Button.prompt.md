The standard action control — amber `primary` for the single most important action on a view, everything else secondary or ghost.

```jsx
<Button variant="primary" icon="terminal">Install pokesay</Button>
<Button variant="secondary" size="sm" iconAfter="arrow-up-right">View source</Button>
```

Variants: primary (amber), brand (moss), secondary (steel outline), ghost, danger. Sizes sm/md/lg. `sticker` adds the hard ink shadow — use it on hero CTAs only. Labels are sentence case, no emoji.
