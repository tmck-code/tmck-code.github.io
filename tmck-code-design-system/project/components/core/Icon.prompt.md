Renders a Lucide glyph via CSS mask — use it anywhere an icon is needed; it inherits `color`, so set colour on the parent.

```jsx
<span style={{ color: 'var(--text-muted)' }}><Icon name="git-branch" size={16} /></span>
```

Names are kebab-case Lucide names. Icons are monochrome only — never fill or multicolour them. Brand-relevant names: terminal, code, git-branch, github, star, git-fork, package, zap, palette, book-open, rss, gamepad-2, headphones, settings, chevron-right, arrow-up-right, copy, check, x, circle-alert.
